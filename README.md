# 📈 Challenge — Prévision des séries temporelles

## 🎯 À propos du challenge

Je me suis lancé un **challenge personnel pour apprendre et maîtriser progressivement la prévision des séries temporelles (Time Series Forecasting) avec Python**.

L'objectif est d'aller au-delà de la théorie en mettant en pratique chaque concept à travers des **notebooks Python, des visualisations, des analyses, des expérimentations et des modèles de prévision**.

Le parcours commence par la compréhension et l'exploration des séries temporelles, puis évolue progressivement vers les méthodes statistiques, les modèles avancés, le Deep Learning et les nouveaux modèles de fondation dédiés au forecasting.

Ce challenge me permettra de construire progressivement une démarche complète :

**Explorer → Visualiser → Comprendre → Décomposer → Modéliser → Évaluer → Prévoir**

---

# 📚 Roadmap du challenge

## 1. 📊 Visualisation des séries temporelles

La première étape consiste à apprendre à **lire et comprendre une série temporelle à travers sa représentation graphique**.

Je vais explorer différentes techniques de visualisation afin d'identifier :

- les tendances ;
- la saisonnalité ;
- les variations ;
- les cycles ;
- les anomalies ;
- les changements de comportement.

L'objectif est de développer le réflexe d'**explorer visuellement les données avant de choisir un modèle de prévision**.

**Statut : 🔄 En cours**

---

## 2. 🧩 Décomposition des séries temporelles

Une série temporelle peut être composée de plusieurs phénomènes simultanés.

Ce chapitre consiste à décomposer une série en différentes composantes afin de mieux comprendre sa structure :

- tendance ;
- saisonnalité ;
- résidus.

L'objectif est de passer d'une simple observation graphique à une **compréhension plus approfondie de la structure de la série**.

**Statut : ⏳ À venir**

---

## 3. 🔎 Caractéristiques des séries temporelles

Avant de construire un modèle, il est essentiel de comprendre les propriétés d'une série temporelle.

Ce chapitre sera consacré à l'identification et à l'analyse de différentes caractéristiques permettant notamment de comprendre :

- la dépendance temporelle ;
- l'autocorrélation ;
- la saisonnalité ;
- la tendance ;
- les variations.

L'objectif est de mieux comprendre **le comportement des données avant leur modélisation**.

**Statut : ⏳ À venir**

---

## 4. 🛠️ Boîte à outils de la prévision

Ce chapitre regroupe les outils et méthodes fondamentaux nécessaires pour construire des prévisions fiables.

Je vais travailler sur :

- la préparation des données ;
- les transformations ;
- la séparation des données ;
- la validation ;
- les mesures d'erreur ;
- l'évaluation des prévisions ;
- les intervalles de prévision.

L'objectif est de construire une démarche **rigoureuse et reproductible pour les projets de forecasting**.

**Statut : ⏳ À venir**

---

## 5. 🧠 Prévisions basées sur le jugement

Les données historiques ne permettent pas toujours de prendre en compte les événements futurs ou les connaissances du domaine.

Ce chapitre explore le rôle du **jugement humain et de l'expertise métier** dans la construction des prévisions.

L'objectif est de comprendre comment combiner les informations disponibles dans les données avec **le contexte et les connaissances du domaine**.

**Statut : ⏳ À venir**

---

## 6. 📈 Modèles de régression pour les séries temporelles

Une série temporelle peut être influencée par plusieurs facteurs externes.

Ce chapitre explore les modèles de régression appliqués aux séries temporelles afin d'intégrer des **variables explicatives** dans les prévisions.

L'objectif est de comprendre comment exploiter les relations entre plusieurs variables pour **améliorer la qualité des prévisions**.

**Statut : ⏳ À venir**

---

## 7. 📉 Lissage exponentiel

Les méthodes de lissage exponentiel constituent une famille importante de méthodes de prévision.

Je vais étudier comment ces méthodes permettent de modéliser :

- le niveau ;
- la tendance ;
- la saisonnalité.

L'objectif est de comprendre comment des modèles relativement simples peuvent produire **des prévisions efficaces et interprétables**.

**Statut : ⏳ À venir**

---

## 8. 🔢 Modèles ARIMA

Les modèles ARIMA sont parmi les méthodes statistiques les plus connues pour la prévision des séries temporelles.

Ce chapitre sera consacré à la compréhension et à l'application des modèles :

- AR ;
- MA ;
- ARIMA ;
- SARIMA ;
- différenciation ;
- modèles saisonniers.

L'objectif est de comprendre **comment modéliser les dépendances temporelles et choisir un modèle adapté aux données**.

**Statut : ⏳ À venir**

---

## 9. 🔄 Modèles de régression dynamique

Dans les problèmes réels, une variable peut dépendre à la fois de son historique et de facteurs externes.

Les modèles de régression dynamique permettent de combiner ces deux dimensions.

L'objectif est de comprendre comment intégrer **les variables explicatives et la dynamique temporelle dans un même modèle de prévision**.

**Statut : ⏳ À venir**

---

## 10. 🌳 Prévision des séries temporelles hiérarchiques et groupées

Dans de nombreux contextes professionnels, les données sont organisées selon plusieurs niveaux.

Par exemple :

**Entreprise → Pays → Région → Agence**

ou

**Entreprise → Catégorie → Produit**

Ce chapitre explore les méthodes permettant de produire des prévisions cohérentes à travers ces différents niveaux.

L'objectif est de construire des prévisions **cohérentes entre les différents niveaux d'une hiérarchie**.

**Statut : ⏳ À venir**

---

## 11. 🚀 Méthodes avancées de prévision

Après avoir étudié les méthodes classiques, ce chapitre permettra d'aller plus loin avec des techniques avancées de forecasting.

L'objectif est d'explorer différentes approches capables de traiter des séries plus complexes et d'améliorer les performances des modèles.

Je chercherai notamment à comprendre :

- quand utiliser ces méthodes ;
- leurs avantages ;
- leurs limites ;
- leur performance par rapport aux méthodes classiques.

**Statut : ⏳ À venir**

---

## 12. ⚙️ Problématiques pratiques de la prévision

Dans les projets réels, les données sont rarement parfaites.

Ce chapitre sera consacré aux problèmes pratiques rencontrés lors de projets de forecasting :

- données manquantes ;
- valeurs aberrantes ;
- transformations ;
- changements de comportement ;
- choix de l'horizon de prévision ;
- incertitude ;
- évaluation des modèles.

L'objectif est de passer d'une approche théorique à une approche **réaliste et applicable dans des projets professionnels**.

**Statut : ⏳ À venir**

---

## 13. 🤖 Réseaux de neurones

Après les méthodes statistiques, ce chapitre introduira les approches basées sur le **Deep Learning**.

Je vais explorer comment les réseaux de neurones peuvent apprendre des relations complexes et non linéaires dans les séries temporelles.

L'objectif sera également de comparer les approches basées sur les réseaux de neurones avec les **méthodes statistiques traditionnelles**.

**Statut : ⏳ À venir**

---

## 14. 🧠 Modèles de fondation pour la prévision

Les modèles de fondation représentent une nouvelle évolution dans le domaine de l'intelligence artificielle.

Ce chapitre sera consacré à l'exploration des **Foundation Forecasting Models** et à leur utilisation pour les séries temporelles.

L'objectif est de comprendre comment ces modèles peuvent être utilisés pour produire des prévisions avec une approche différente des modèles traditionnels.

**Statut : ⏳ À venir**

---

## 15. 🚀 Synthèse et mise en pratique

Cette dernière étape permettra de mettre en perspective l'ensemble des méthodes étudiées durant le challenge.

L'objectif sera de comparer différentes approches sur des problèmes de forecasting et de déterminer :

- quelle méthode utiliser ;
- dans quel contexte ;
- avec quelles données ;
- comment évaluer les résultats ;
- quelles sont les limites de chaque approche.

Cette étape permettra de transformer les connaissances acquises en **une véritable démarche de résolution de problèmes de forecasting**.

**Statut : ⏳ À venir**
